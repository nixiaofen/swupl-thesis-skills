# 学位论文完稿体检

写作阶段用 `law-thesis-refs`（找文献、挂注、维护素材）；**写完之后用本技能**。前者是生产线，后者是质检。

产出一份**体检报告**，只报问题、不改正文——改不改由你定。

## 何时使用

- 用户说"帮我查一遍""提交前检查一下""引注核对""注号乱了""参考文献去重"
- 五章都写完，准备合并 / 送审 / 答辩
- 新增一批文献后，担心注号顺移出错

## 用法

```bash
PY="%USERPROFILE%\.workbuddy\binaries\python\envs\default\Scripts\python.exe"

"$PY" scripts/audit.py --dir <论文项目根目录> --out 体检报告.md
"$PY" scripts/audit.py --dir . --refs 参考文献.md        # 把参考文献列表纳入格式检查
"$PY" scripts/audit.py --dir . --pages 文献页码总表.csv  # 启用页码越界检查
```

**目录约定**（脚本会自动发现，不符合才需显式指定）：

```
02-章节草稿/第*章-*.md      章节稿（自动排除 bak / 试写 / 留档）
02-章节草稿/定稿同步-*.md   已定稿部分
02-章节草稿/摘要*.md、结语*.md
03-素材库/全文立场一致性清单.md
03-素材库/refs_pages.csv    文献页码总表（可选）
```

**章节稿格式**：正文在前，脚注在 `## 【脚注】` 之后，注号用 `〔1〕` 或 `[1]`。

## 六项检查

| # | 检查 | 拦什么 | 真实教训 |
|---|---|---|---|
| 1 | **无源论断审计** | 捞出全部"有学者／有观点／论者／有法院"句，逐句看句内有没有注；没注的**逼你回原文确认"人是谁、说过什么"** | 某章"有学者主张可参照异议股东回购请求权中的'合理价格'标准"——**查无此人**，是拼出来的 |
| 2 | **注号完整性** | 正文首现顺序是否 1..N 递增；抓**孤儿注**（脚注列了正文从不引用）与**悬空引用** | 插新文献后注号顺移过六七次；发现过一条脚注从头到尾没被引用 |
| 3 | **页码越界** | 所引页码是否落在该文献起止页区间内 | 某文刊物页 18—32，正文却写"第63页"；另一篇 62—70，脚注全数记成 70／71／73 |
| 4 | **引注格式体检** | 篇名是否误用书名号、《期刊名》后是否缺逗号、参考文献是否带了页码、作者 ≥3 是否截为"前 3+等"、重复条目 | 参考文献里同一案号出现两次；译著混排在论文类里 |
| 5 | **立场一致性** | 清单里**未闭合的张力点**有几项——写下一章前必须先处理 | （二）3"丧失股东资格" vs（三）1"股权本身未消灭"，靠清单才被发现 |
| 6 | **摘要/结语/引言重复率** | 按 6-gram 算重叠比。结语 >20% 报警，引言 >15% 报警（规范明令"引言不要与内容摘要雷同"） | 结语第一版写成摘要的复述，重叠率极高；改成升华式后降到 5.2% |

### 页码总表 CSV（第 3 项的前提）

第 3 项**必须**有这张表才能跑，否则只能跳过。格式：

```csv
作者,篇名,刊物,起始页,结束页
邹海林,公司资本充实原则：逻辑和制度发展,比较法研究,18,32
李欢,论除名制度与失权制度的功能互补,北京理工大学学报（社会科学版）,62,70
```

每张新文献读完后顺手加一行，比事后补救便宜得多。

## ⚠️ 边界（别高估它）

1. **只查机械可判定的东西。** 观点是否成立、论证是否充分、文献是否被曲解——脚本查不出。"看起来很对其实是错的"只能靠人通读。
2. **不改正文。** 只出报告，改不改你定（这一点刻意如此：自动改正文风险远大于收益）。
3. **第 5 项是清单驱动的**，不是自动推理——它检查你维护的一致性清单里还有多少未闭合张力点，不会替你判断两个论断是否矛盾。
4. **检查 4 的启发式有误报可能**（如"末尾缺句号"对半角句点会误报），报告里的每一条都要人眼过一遍。

## 与 `cnki-to-xizheng` 的分界

- `cnki-to-xizheng`：书目条目层面的**生产**——知网题录 → 西政脚注／参考文献格式。
- `thesis-final-audit`：全文层面的**质检**——格式、注号、页码、立场、重复率。
- 体检报告里"格式不合规"的条目，回到 `cnki-to-xizheng` 重新生成即可，两者配合。
