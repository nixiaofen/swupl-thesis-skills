# 知网题录 → 西南政法大学论文引注格式

把知网导出的一批题录，**一次性**转成西政硕士学位论文要求的脚注与参考文献格式。

## 何时使用

- 用户说"把知网的引文格式改成西政的""批量转脚注""参考文献格式转换"
- 手里有一份从知网导出/复制的题录清单（几条到几百条），要逐条改成论文格式
- 需要同时产出**脚注**（带页码）和**参考文献**（不带页码）两个版本

不用于：改已排版 Word 里的脚注（那是 `footnote-format-revision`）；写作过程中的引注管理（那是 `law-thesis-refs`）。

## 规范依据（原文摘录，勿凭记忆改动）

《西南政法大学硕士学位论文格式要求》（2023-03-01）第七、八部分：

| 类型 | 格式 |
|---|---|
| **期刊文章** | 作者："篇名"，《期刊名》，期刊号，页码。 |
| 中文专著 | 作者：《专著名》，出版地：出版者，出版年，页码。 |
| 学位论文 | 作者："论文题目"，所在学校博（硕）士论文，毕业年份，页码。 |
| **参考文献** | 「各类参考文献的格式**除毋需列明页码外**，其余与注释的格式相同」 |
| 作者数量 | 少于 3 人全部写出，3 人以上只列前 3 人，后加"等"；作者间用「，」 |

⚠️ **两处最容易写错**：
1. **《期刊名》后面有逗号**（原文作「《期刊名》，期刊号，页码」）；
2. **篇名用中文引号“ ”，不是书名号**——书名号只给期刊名／专著名。

## 用法

```bash
PY="%USERPROFILE%\.workbuddy\binaries\python\envs\default\Scripts\python.exe"

"$PY" scripts/cnki2xz.py 题录.txt                  # 默认同时输出脚注版 + 参考文献版
"$PY" scripts/cnki2xz.py 题录.txt --mode footnote  # 只要脚注
"$PY" scripts/cnki2xz.py 题录.txt --mode ref       # 只要参考文献
"$PY" scripts/cnki2xz.py 题录.txt --out 结果.md    # 写入文件
"$PY" scripts/cnki2xz.py 题录.txt --degree 博      # 学位论文按"博士论文"输出（默认"硕"）
```

**输入格式自动识别，无需指定**。已支持四种：

| 格式 | 样例 |
|---|---|
| 知网「引文格式」 | `吴芳.有限责任公司股东除名规则之检讨与完善[J].现代法学,2021,43(2):106-118.` |
| GB/T 7714（带空格） | `刘俊海. 论股权平等原则[J]. 法学杂志, 2008, 29(3): 32-36.` |
| RefWorks（导出） | `RT Journal Article` / `A1 吴芳` / `T1 …` / `JF 现代法学` / `YR 2021` / `IS 2` / `SP 106` / `OP 118` |
| EndNote RIS / 旧式 | `TY  - JOUR` + `AU`/`TI`/`JO`/`PY`/`IS`/`SP`/`EP`，或 `%0`/`%A`/`%T`/`%J`/`%D`/`%N`/`%P` |

`examples/` 下有四种格式的样例文件，可直接跑来验证。

## 转换示例

输入（知网引文格式）：
```
吴芳.有限责任公司股东除名规则之检讨与完善[J].现代法学,2021,43(2):106-118.
```

输出·脚注：
```
吴芳：“有限责任公司股东除名规则之检讨与完善”，《现代法学》，2021年第2期，第106-118页。
```

输出·参考文献：
```
吴芳：“有限责任公司股东除名规则之检讨与完善”，《现代法学》，2021年第2期。
```

卷号 `43` 被丢弃（西政只要求"期刊号"＝年份＋期号）；`106-118` → `第106-118页`。

## ⚠️ 边界与限制（转换后必须人工过一遍）

脚本只做**确定性文本转换**，以下情形一律在输出末尾的「⚠️ 需人工确认」区列出，**不要假装已经转好**：

1. **字体、上标、引号字形不在脚本职责内。** 脚本输出的引号是中文引号字符 “ ”；它在 Word 里显示成中文还是西文字形，取决于段落样式——正确做法是**中文字体设宋体、西文字体设 Times New Roman**，这样中文标点走中文字形、数字走 Times New Roman。**若整段设成 Times New Roman，中文引号会被西文字形替代**，这是排版问题，不是文本问题。
2. **学位论文的硕/博无法自动判断**（知网 `[D]` 不区分）。默认输出"硕士论文"，用 `--degree 博` 切换，且总会提示确认。
3. **专著没有页码**（知网题录不含具体引用页）。输出会提示"正文引用时须补具体页码"。
4. **外文作者未做"姓前名后、名缩写"处理**，含英文人名的条目须人工核。
5. **不支持的类型**（`[C]` 论文集、`[N]` 报纸、`[S]` 标准、`[EB]` 电子文献、`[Z]` 其他等）不会瞎转，只输出"请手工转换"。
6. **再次引用**（"作者：前注X，第X页"）与**转引**（"…… 转引自……"）是引用关系而非书目信息，脚本不处理，须人工加。
7. **裁判文书、法律法规**西政规范未单列，脚本不覆盖，按学校/导师口径处理。

## 交付前自检

- [ ] 每条的**篇名用“ ”、期刊名用《 》**，没有用反
- [ ] 《期刊名》后有逗号，年份写作"2021年第2期"
- [ ] 作者≥3 人的已截为前 3 人 + "等"，间隔是全角逗号
- [ ] 参考文献版本**没有页码**，脚注版本**有页码**
- [ ] 末尾句号都在，没有半角逗号
- [ ] 「⚠️ 需人工确认」区里的每一条都已处理

Python venv `%USERPROFILE%\.workbuddy\binaries\python\envs\default`，**无需任何第三方库**（只用 `argparse`/`re`/`sys`），可直接分发使用。
